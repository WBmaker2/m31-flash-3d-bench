# 3D 기차 레일

빈 칸을 눌러 **선로를 놓고** 방향을 정해 역과 역을 잇는 게임입니다.
길이 이어지면 기차가 달려갑니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/rail/
```

## 조작

- **빈 칸 누르기** — 선로를 놓고, 다시 누르면 돌리고, 한 번 더 누르면 뺍니다
- **직선 / 곡선** — 어떤 조각을 놓을지 고릅니다
- **Space** — 채점 · **R** — 비우기
- 마우스 드래그로 시점 바꾸기

## 규칙

- 직선 조각은 위↔아래, 좌↔우 중 하나를 잇습니다
- 곡선 선로는 이웃한 두 방향(예: 위↔우)을 잇습니다
- 서로 맞닿은 조각이 방향이 이어져야 길이 됩니다
- **도착역**은 선로가 없어도 도착으로 봅니다
- 별점은 길이 연결되고 최소 개수 이하로 놓으면 3성입니다

## 구조

| 파일 | 역할 |
|---|---|
| `common/parts/rail3d.js` | 조각 포트 · 연결 · 경로 탐색 · 최단 경로 (순수 함수, three 불필요) |
| `src/levels.js` | 레벨 8종 + par + 미션 판정 (순수 함수) |
| `src/railView.js` | 판 · 선로 조각 · 역 · 기차 |
| `src/stage.js` | 렌더러·조명·카메라 4시점 · 고정 스텝 루프 |
| `src/invariants.js` | 기하 불변식 (선로 유한 · 경로 연속 · 진행률 범위) |
| `src/hud.js` | HTML 연결 + 놓은 개수 |
| `src/controls.js` | 포인터·키보드 입력 해석 |
| `src/main.js` | 상태 머신(놓기·회전·경로·기차) + UI 배선 |
| `common/parts/rail3d.test.js` · `src/levels.test.js` | 단위 테스트 19개 |

## 설계 메모

- **연결은 포트로 판단합니다.** 조각이 가진 두 방향 중 하나로만 나갈 수 있습니다.
- **경로 탐색은 실제로 이어진 조각만 통과합니다.** 방향이 안 맞으면 길이 끊깁니다.
- **최소 조각 수(par)는 최단 경로의 빈 칸 수입니다.** 도착역은 세지 않습니다.
- **기차는 완성된 경로를 따라 움직입니다.** 길이 열리면 자동으로 출발합니다.

## 검증

```bash
node ../scripts/shot.mjs rail    # 4시점 캡처 + 자동 판정
npx vitest run rail common/parts # 단위 테스트 19개
```
