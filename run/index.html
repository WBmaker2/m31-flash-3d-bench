책 뒤쪽 · 직접 실행

이 페이지는 저장소를 직접 확인하는 분을 위한 안내입니다. 빌드 단계가 없고, 정적 서버만 있으면 바로 실행됩니다. 게임 18종은 모두 브라우저 안에서 동작합니다.

python3 -m http.server 5174
npm test
npm run qa
npm run qa:ui
npm run qa:cards

로컬 서버를 띄운 뒤 http://localhost:5174/를 열면 랜딩에서 바로 플레이할 수 있습니다. 게임 폴더만 따로 열 때도 저장소 루트의 common/과 vendor/가 필요합니다.
