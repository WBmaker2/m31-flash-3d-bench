## 1. 왜 이 게임인가 — 기존 13종과 축 분리

| 게임 | 검증하는 능력 |
|---|---|
| `zoo/` ~ `sculpt/` | 절차적 지오메트리 · 화학 규칙 · 상태 머신 · 격자 배치 · 수치 적분 · 역기구학 · 최단 경로 · 에머전트 행동 · 암시적 곡면 |
| `gears/` | 회전 동역학 + 기어비 전파 + 톱니 위상 |
| `paint/` | 표면 셀 그래프 + 국소 flood fill + 색 비교 채점 |
| `dice/` | 시드 난수 결정론 + 자세→면 매핑 + 턴 상태 머신 |
| `balance/` | 역학 평형(모멘트) + 무게중심 + 최소 추 열거 |

**이번에 새로 검증하는 능력**

1. **캐릭터 컨트롤러** — 앞의 13종엔 스스로 움직이는 주어가 없었다. 가속·감속·마찰로
   움직이는 몸통을 만든다.
2. **스윕(CCD) 충돌** — 낙하 속도가 스텝 사이클만큼 내려가도 구름을 **뚫지 않는다**.
   구간-면 교차로 판정한다.
3. **점프 궤적** — 점프 높이·비행 시간·도달 거리가 숫자로 계산된다.
4. **3인칭 카메라 리그** — 카메라가 주체를 따라가되, 주체가 화면에서 사라지지 않는다.
5. **도달 가능성** — 다음 구름까지의 간격이 점프로 넘을 수 있는 거리 이내인지
   레벨이 보장한다.

**판정이 "잘 보이면"이 아니라 숫자다.** 착지는 구간 교차로 판정하고, 스텝 크기를
두 배로 해도 같은 구름에 서는지 테스트한다.

## 2. 게임 정의

**핵심 루프**: 구름을 밟으며 앞으로 뛰어 동전과 깃발(결승점)에 도달한다.

- **플레이어 조작**
  - **← →** (또는 A · D) — 좌우 이동 · **Space** — 점프
  - 구름 사이를 건너뛰고 코인(동전)을 모아 간다
  - 깃발에 닿으면 통과
- **판정**: 결승점 도달 여부 + 모은 동전 수
- **별점**: 별3 = 결승점 도달 + 동전 전부 수집 · 별2 = 결승점 도달 · 별1 = 동전 1개 이상 ·
  별0 = 실패
- **레벨**: 8종. 구름 간격·높이 차·동전 배치가 다르다
- **추가 규칙**: 떨어져도 즉시 위로 돌아오지 않는다(처음 위치로). 대신 재시도 버튼

## 3. 수치 계약

| 값 | 값 | 단위 |
|---|---|---|
| 중력 | 18 | m/s² |
| 점프 속도 | 7.0 | m/s |
| 이동 속도 | 4.6 | m/s |

| 지상 가속 | 26 | 1/s |

| 고정 스텝 | 1/60 | s |
| 점프 최고 높이 | 1.36 | m (= v²/2g) |
| 점프 비행 시간 | 0.78 | s (= 2v/g) |
| 최대 도달 거리 | 3.58 | m |

### 착지 판정 (스윕)

한 스텝 동안 캐릭터의 바닥이 `fromY → toY` 로 내려간다.
`fromY ≥ 구름 윗면 ≥ toY` 이고 수평으로 겹치면 **그 구름 위에 선다**.
스텝이 커져도 뚫지 않는다.

## 4. 레벨 8종

| # | 레벨 | 구름 수 | 간격 | 동전 | 특징 |
|---|---|---|---|---|---|
| 01 | 첫 구름 | 5 | 1.6 | 3 | 같은 높이 |
| 02 | 오르막 | 6 | 1.8 | 4 | 높이가 오른쪽으로 |
| 03 | 내리막 | 6 | 1.8 | 4 | 높이가 오른쪽으로 ↓ |
| 04 | 좁은 구름 | 7 | 2.2 | 5 | 구름 폭이 좁다 |
| 05 | 높은 구름 | 7 | 2.4 | 5 | 높이 차가 크다 |
| 06 | 코인 길 | 8 | 2.0 | 8 | 동전이 길게 이어진다 |
| 07 | 큰 구름 | 8 | 2.6 | 6 | 마지막에 넓은 구름 |
| 08 | 하늘 성 | 9 | 2.8 | 7 | 가장 길고 높다 |

**레벨은 코드로 고정한다.** 각 레벨에 대해
1. 모든 인접 구름 간격이 최대 도달 거리 이내인지,
2. 점프 최고 높이보다 큰 높이 차가 인접 구름 사이에 없는지,
3. 코인이 전부 구름 위(또는 점프 궤적 근처)에 있는지
단위 테스트가 확인한다.

## 6. 검증 3층

### 1층 — 단위 테스트

| 묶음 | 검증 내용 |
|---|---|
| 중력 적분 | 고정 스텝 60번의 낙하 거리 = ½gt² 와 오차 1e-9 |
| 최대 낙하 속도 | 속도가 22 를 넘지 않는다 |
| 점프 궤적 | 최고 높이 = v²/2g · 비행 시간 = 2v/g ±1e-9 |
| 스윕 착지 | 빠른 낙하(스텝 10배)도 구름 위에서 멈춘다 · 구름을 뚫지 않는다 |
| 스텝 독립성 | 스텝을 2배로 해도 같은 구름에 선다 |
| 수평 판정 | 겹치지 않으면 착지하지 않는다 · 경계 위는 선다 |
| 레벨 | 8종 모두 간격 ≤ 최대 도달 거리 · 높이 차 ≤ 점프 높이 |

### 2층 — 기하 불변식 (0.5초마다)

캐릭터 좌표 유한 · 캐릭터가 구름 안에 박혀 있지 않음(바닥이 구름 윗면 위) ·
동전 좌표 유한 · 낙하 속도 한계 이내 · 구름 위 높이에 서 있으면 낙하 속도 0

### 3층 — 화면 판정
