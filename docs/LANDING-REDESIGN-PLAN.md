## 1. 왜 바꾸는가

현재 랜딩은 **모델 벤치마크 리포트**로 읽힙니다. 그러나 확인된 제품 맥락은 다릅니다.

- 주 방문자: **교사·학생**
- 성공: **18개 카탈로그 전체를 훑고, 관심 있는 게임을 찾는 것**
- 정체성: **게임 쇼케이스** (검증은 신뢰 장치)

지금 화면은 이 순서와 반대입니다. 첫 문장은 "3D 게임 18종을 모델이 직접 만들었습니다"로 모델이 주인공이고, 첫 섹션은 기록이 없는 사람에게 빈 `MY PROGRESS`입니다. 정작 게임 18개는 두 번째 섹션의 2열 카드 벽이고, 카드마다 `단위 테스트 / 콘솔 오류 / 불변식 위반 / 시점 간 화면 차이` 네 줄이 붙어 있습니다. 교사가 "무엇을 같이 해볼 수 있지?"를 묻는 화면이 아니라, 평가자가 "모델이 잘했나?"를 확인하는 화면입니다.

### 지킬 것

- 18개 게임이 실제로 플레이된다. 모달 iframe, `PLAY` 버튼, localStorage 진행 기록이 동작한다.
- 랜딩 수치는 `docs/checks.json`과 대조된다. **홍보 페이지가 거짓말하지 못하는 구조**를 유지한다.
- 빌드 단계 없음, 정적 호스팅, 한국어 UI, 모바일 터치, `prefers-reduced-motion`.
- `docs/cards/`의 실제 게임 화면 54장. 새 가짜 목업을 만들지 않는다.
- `npm test`, `npm run qa`, `npm run qa:ui`의 계약.

### 바꿀 것

1. **첫 화면의 주인공**을 모델에서 게임으로 바꾼다. 첫 문장이 "무엇을 할 수 있는지"를 말한다.
2. **정보 구조**를 카탈로그 우선으로 바꾼다. 진행 기록은 게임 뒤로 보낸다.
3. **18개 카드의 밀도**를 낮춘다. 카드에는 이름·한 줄·검사 1개만, 네 가지 수치는 검증 스프레드로 모은다.
4. **검증**은 별도 벤치마크 섹션이 아니라 책 뒤쪽의 책갈피·콜로폰으로 만든다.
5. **개발자용 RUN**은 교사·학생의 동선에서 빼고 책 뒤쪽으로 보낸다.
6. **다크 터미널/앰버 BENCH 아이덴티티를 폐기**한다. 새 세계는 종이·카드스톡·팝업의 밝은 세계다. 현재 룩은 안티레퍼런스로만 쓴다.
7. **모바일 첫 화면**에서 빈 진행 패널을 걷어내고, 책의 첫 장과 세계 목차가 먼저 보이게 한다.

## 2. 선택된 방향 — 입체 팝업북

### Direction contract

**THESIS**
18개의 3D 게임을 **한 권의 입체 팝업북**으로 만든다. 표지와 카드 그리드가 아니라, 펼친 책의 두 페이지·거터·탭 레일·팝업 무대가 화면의 구조다. 카테고리가 늘 하는 "큰 헤드라인 + 균일한 카드 그리드"와 "다크 터미널 벤치마크"를 둘 다 거부한다.

**OWN-WORLD**
두꺼운 크림색 카드스톡(`#f4ead8`)이 바탕이고, 페이지 가장자리는 `#e3d4bb`, 접힌 자리와 그림자는 `#cbb896`. 게임 세계는 색지 레이어—주홍 `#b93d29`, 코발트 `#2f5fa8`, 황토 `#d9a62e`, 풀색 `#6f9b52`—로 튀어나온다. 잉크는 `#2b2118`, 작은 글씨는 `#6b5a45`. 책은 어두운 책상(`#2b1e14`) 위에 놓인다. 탭은 책의 앞장 가장자리에 붙은 색지 탭이고, 활성 탭만 10px 더 나온다. 버튼은 종이 탭처럼 아래로 5px 두께의 단단한 그림자를 가진다. 유리·네온·글래스모피즘·금색 펄스 장식은 쓰지 않는다. `btn-pulse`는 주 행동에만 금빛 링으로 남긴다.

**STORY**
방문자는 책이 펼쳐진 첫 장에서 3D 세계 하나가 종이로 튀어나온 것을 본다. 오른쪽 페이지의 탭 레일에서 18개 세계의 범위를 파악하고, 관심 있는 탭을 눌러 그 세계의 장으로 간다. 각 장의 팝업 무대 위에 있는 "이 세계로 들어가기"를 누르면 그 자리에서 게임이 열린다. 진행은 탭에 찍히는 관찰 스탬프로 쌓이고, 책 뒤쪽에서 검증 기록과 실행 방법을 확인한다.

**FIRST VIEWPORT**
1440×900에서 책 한 권이 화면을 채운다. 왼쪽 페이지(약 48%)는 첫 세계 `폴리곤 동물원`의 팝업 무대—실제 `docs/cards/zoo-card.png`를 색지 레이어가 감싸고, 무대 위에 "이 세계로 들어가기" 버튼이 있다. 오른쪽 페이지(약 52%)는 작은 마크, 큰 명조 헤드라인 "18개의 세계를 펼치면, 바로 플레이.", 두 줄 설명, 앞장 가장자리의 18개 탭, "18개 세계 전체 목차 →" 링크, 아래쪽에 "18개 세계 · 615개 검사 · 콘솔 오류 0" 한 줄. 주 행동은 왼쪽 무대의 플레이 버튼 하나이고, 탭은 보조 내비게이션이다. 1280에서는 책이 1150px로 줄고, 980 이하에서는 한 페이지짜리 책으로 접힌다. 390에서는 무대가 위, 헤드라인·탭이 아래, 탭은 가로 스크롤 스트립이 된다.

**FORM**

**FINISH**

### 세계 규칙

- **하나의 책, 한 번에 한 펼침.** 페이지는 항상 두 페이지와 하나의 거터다. 세 번째 패널이나 가짜 접힘을 만들지 않는다. 더 많은 내용은 다음 펼침으로 간다.
- **팝업은 장식이 아니라 무대.** 각 게임의 실제 스크린샷이 색지 레이어 사이에 서고, 플레이 버튼은 그 무대 위에 있다. 팝업 레이어는 `aria-hidden` 장식이고, 정보는 라벨과 버튼이 담당한다.
- **탭은 책의 앞장 가장자리.** 18개 탭은 게임 번호와 이름을 가진 앵커다. 활성 탭은 10px 더 나오고, 나머지는 같은 두께로 숨 쉰다. 탭만 보고도 18개의 범위가 읽혀야 한다.
- **검증은 책 뒤쪽.** 카드에는 `검사 25` 정도만 두고, 네 가지 수치 전체는 책 뒤쪽의 "게임별 검증 기록" 접이식 표에 둔다. 숨겨도 DOM에는 남겨 `shot.mjs`의 `data-check` 대조를 유지한다.
- **색은 게임이 가져온다.** 책의 크림·잉크·색지가 고정이고, 18개 스크린샷의 색이 페이지마다 달라진다. 책 자체에 그라데이션·네온을 더하지 않는다.

### 왜 이 순서인가

- 첫 방문자의 질문은 "무엇이 있나?"이고, 두 번째 질문은 "어떤 걸 먼저 해볼까?"다. 진행 기록은 그다음이다.
- 첫 화면의 탭 레일이 18개 전체를 즉시 보여주고, 02 목차가 한 번 더 텍스트로 훑게 한다. 카탈로그 탐색 성공 기준을 두 겹으로 받친다.
- 검증은 카탈로그를 가로막지 않으면서, 신뢰가 필요한 사람에게는 책 뒤쪽에서 전부 보여준다.

### 패널 구성

각 게임 패널은 다음만 보인다.

- 번호 `01` (모노, 작게)
- 게임 이름 (명조, 22–28px)
- 능력 한 줄 (예: "절차적 모델링")
- 설명 한 줄 (현재 카드 설명을 1문장으로 줄임)
- `검사 25` (모노, 작게)
- `플레이` 종이 탭

네 가지 수치 전체는 07의 접이식 표로 간다. 현재 카드의 `0건 / 0건` 반복이 사라져 이름과 설명이 읽힌다.

### 18개 `.play` 계약

`scripts/shot.mjs`는 `.play`가 정확히 18개이고, `#progress-grid .progress-item`도 18개이길 기대한다. 첫 장의 zoo가 대표 카드가 되고, 03 그룹에서는 zoo를 패널이 아니라 "이 책의 첫 장" 안내로만 참조한다. 따라서 **1(첫 장) + 5(그룹 1) + 6(그룹 2) + 6(그룹 3) = 18**이다. 목차의 zoo 행은 첫 장으로 스크롤하는 링크다.

색 전략은 **풀 팔레트(3–4 역할)**다. 크림 종이가 60% 이상을 차지하고, 색지는 게임 세계마다 달라지는 역할색이다. 작은 글씨에 주홍을 쓰지 않는다. 잉크/종이 대비는 10:1 이상, 주홍 진한/종이 대비는 4.5:1 이상을 목표로 한다.

### 글자

| 역할 | 폰트 | 크기 | 쓰임 |
|---|---|---|---|
| 디스플레이 | **Nanum Myeongjo** 700 | h1 `clamp(36px, 4.4vw, 58px)`, h2 30–44px, 게임명 18–32px | 헤드라인, 게임 이름 |
| 본문·라벨 | **Nanum Gothic Coding** 400/700 | 11–15px, 라벨 9–12px | 설명, 버튼, 탭 이름 |

- 폰트는 자체 호스팅한다. `scripts/sync-fonts.mjs`의 `FAMILIES`에 Nanum Myeongjo(700)를 추가하고 `npm run fonts`로 `vendor/fonts/`에 내려받는다.
- 용량 가드 결과: Gowun Dodum(400/700)을 함께 받으면 추가 4.10MB로 1.5MB를 넘었다. 계획대로 Gowun Dodum을 빼고 기존 `Nanum Gothic Coding`을 본문·라벨에 쓴다. Nanum Myeongjo는 700만 받아 추가 1.36MB로 유지한다.
- IBM Plex Mono는 본문에 쓰지 않는다. 터미널 느낌은 숫자에만 남긴다.

### 레이아웃·질감

- 책 최대 폭 1240px, 페이지 여백 `clamp(22px, 3.2vw, 48px)`, 거터 36px, 탭 레일 66px.
- 팝업 무대 비율 16:10(카드 이미지와 동일). 무대 위 스크린샷은 `object-fit: cover`.
- 종이 질감은 CSS 반복 그라데이션과 아주 옅은 노이즈로만 만든다. 종이 사진을 새로 만들지 않는다.
- 버튼·탭은 아래로 5px 두께의 단단한 그림자. 부드러운 블러 그림자는 책상 위 책 그림자에만.
- 한 가지 리듬: 섹션 위 여백이 아래보다 크다. 밀도가 높은 목차 뒤에는 조용한 검증 책갈피를 둔다.
- 괘선은 1px 실선 또는 점선. 카드마다 다른 둥근 모서리를 쓰지 않는다. 책의 모서리는 2–6px만.

### 모션

- **탭 클릭**: 해당 장으로 스크롤하고, 탭이 10px 나오며, 도착한 무대가 14px 떠오른다(320ms, `cubic-bezier(.2,.8,.2,1)`).
- **플레이 버튼**: hover에서 2px lifted, active에서 그림자가 2px로 줄어드는 "종이 눌림".
- **페이지 진입**: 각 펼침은 한 번만 12px 떠오른다. 스크롤 패럴랙스·자동 넘김·스크롤 하이재킹 없음.
- **모달**: 책상 위로 종이 한 장이 떠오르는 느낌. 200ms, 배경은 `#2b1e14` 86%.
- `prefers-reduced-motion: reduce`에서 모든 변형·이동을 끄고 즉시 상태만 바꾼다. `btn-pulse`도 끈다.

|---|---|---|---|
| 1440 | 2페이지, 1240px | 오른쪽 세로 레일 18개 | 무대 + 헤드라인 + 탭 |

- 390에서 가로 스크롤이 생기면 실패다. 탭 스트립만 `overflow-x: auto` + `scroll-snap`.
- 모바일에서 hover 프레임 순환은 동작하지 않아도 된다. 첫 프레임이 항상 보인다.
- 모바일 헤더는 마크가 두 줄로 접히지 않게 `목차`·`내 기록`만 남긴다.

### 접근성

- 탭 레일: `<nav aria-label="세계 목차">` + `<a href="#game-zoo" aria-label="01 폴리곤 동물원">`. 현재 항목은 `aria-current="true"`.
- 각 게임 패널: `<article data-game="...">` + `<h3>`. 플레이 버튼은 `aria-label="${title} 플레이"`.
- 스크린샷 `alt`: 게임 이름 + 장면 한 줄(예: "폴리곤 동물원 — 저폴리 판다와 고양이가 정원을 걷는 화면"). 장식 색지 레이어는 `aria-hidden`.
- 모달: 기존 `aria-labelledby="player-name"` 유지, 닫을 때 포커스 복귀, `Escape` 닫기.
- 포커스: `outline: 2px solid #2f5fa8; outline-offset: 3px`. 종이 위에서도 보이게.
- `btn-pulse`는 첫 화면의 주 행동에만. 금빛 링(`#d9a62e`)으로 바꾸고 reduced motion에서 끈다.
- 색 대비는 구현 후 계산한다. 작은 글씨에 `#c94a35`를 쓰지 않는다.

## 8. 리스크와 열린 결정

### 리스크

1. **팝업이 장식이 되면 카탈로그가 사라진다.** 무대 위 플레이 버튼, 목차 표, 탭 레일 세 가지로 카탈로그 접근을 보장한다.
2. **책 오브젝트가 모바일에서 과해진다.** 980 이하에서 한 페이지로 접고, 팝업 레이어 수를 줄인다.
3. **폰트 용량이 커진다.** 1.5MB 가드. 넘으면 Gowun Dodum을 빼고 기존 Nanum Gothic Coding을 쓴다.
4. **밝은 랜딩 → 어두운 게임 모달의 대비.** 모달을 책상 위 종이 프레임으로 만들어 "다른 세계로 들어가는 문"으로 설명한다.
5. **18개 탭이 작아진다.** 탭은 번호+이름 `aria-label`을 갖고, 목차 표가 텍스트 대체 경로다.
6. **`data-check` 계약이 깨진다.** 네 가지 수치를 카드에서 빼더라도 책 뒤쪽 표에 모두 남긴다. `shot.mjs`는 숨김 노드도 읽는다.

### 열린 결정

- 그룹 이름과 구성(현재 6·6·6)이 교사에게 자연스러운지. 필요하면 그룹만 조정하고 번호는 유지한다.
- `실행` 섹션은 `run/index.html`로 분리했다. 책 뒤쪽에는 링크만 둔다.
- 새 폰트: Nanum Myeongjo 700만 추가. Gowun Dodum은 4.10MB로 가드를 넘어 제외하고 기존 Nanum Gothic Coding을 쓴다.
- 첫 장의 대표 게임이 zoo가 맞는지. 카탈로그의 첫 항목이라 선택했지만, 다른 게임이 더 대표적이면 교체한다.
- `btn-pulse`를 첫 화면 주 버튼에 유지하는지. 전역 규칙에 따라 유지하고 색만 금빛으로 바꾼다.
