## 1. 왜 이 게임인가 — 기존 12종과 축 분리

| 게임 | 검증하는 능력 |
|---|---|
| `zoo/` ~ `sculpt/` | 절차적 지오메트리 · 화학 규칙 · 상태 머신 · 격자 배치 · 수치 적분 · 역기구학 · 최단 경로 · 에머전트 행동 · 암시적 곡면 |
| `gears/` | 회전 동역학 + 기어비 전파 + 톱니 위상 |
| `paint/` | 표면 셀 그래프 + 국소 flood fill + 색 비교 채점 |
| `dice/` | 시드 난수 결정론 + 자세→면 매핑 + 턴 상태 머신 |

**이번에 새로 검증하는 능력**

1. **역학 평형(토크)** — 저울이 수평이 되려면 모멘트 합이 0이어야 한다.
   앞의 12종엔 "힘의 합"을 다루는 게임이 없다.
2. **무게중심** — 추를 어디에 놓느냐가 결과를 바꾼다. 같은 추라도 팔 길이가
   다르면 다른 무게중심이 나온다.
3. **무게 중심의 조건부 갱신** — 추를 놓을 때마다 무게중심과 기울기가 **다시 계산**되어야 한다.
4. **두 조건 미션** — "수평으로 맞추기"와 "총 무게 맞추기"를 동시에 만족해야 한다.
5. **최소 추 개수(par)** — 최소 몇 개로 두 조건을 맞출 수 있는가.

**판정이 "잘 보이면"이 아니라 숫자다.** 기울기는 모멘트 합과 무게 합에서 계산한
각도와 1e-9로 대조된다.

## 2. 게임 정의

**핵심 루프**: 시소매 저울의 양쪽 판에 추를 올려 **수평으로 맞추고** 총 무게를
목표에 맞춘다.

- **플레이어 조작**
  - 팔레트에서 추 선택(1 · 2 · 3 · 5 kg) → 판의 홈을 클릭 → 추를 올린다
  - 올린 추를 다시 누르면 뺀다
  - 저울이 기울어지며 무게중심 표시가 움직인다
- **판정**: 모멘트 합 == 0 (±1e-9) **그리고** 총 무게 == 목표
- **별점**: 별3 = 두 조건 달성 + 추 개수 ≤ par · 별2 = 두 조건 달성 · 별1 = 한 조건만 ·
  별0 = 실패
- **레벨**: 8종. 받침대 위치·판의 홈·추 종류·목표 무게가 다르다

## 3. 수치 계약

| 값 | 값 | 단위 |
|---|---|---|
| 중력 가속도 | 9.8 | m/s² |
| 추 종류 | 1 · 2 · 3 · 5 | kg |
| 판 홈 간격 | 0.11 | m |
| 저울판 길이 | 0.92 | m |
| 수평 판정 허용 오차 | 1e-9 | N·m |
| 무게 판정 허용 오차 | 1e-9 | kg |
| 최대 기울기 | 0.6 | rad |

### 저울 계산

```
Στ = Σ (m_i · g · (x_i − x_fulcrum))     모멘트 합 (N·m)
Σm = Σ m_i                                무게 합 (kg)
기울기 = atan2(Στ , Σm · g)
무게중심 = Σ(m_i · x_i) / Σm
```

수평(무게중심 == 받침대 위치) ⟺ `Στ == 0`.

## 4. 레벨 8종

| # | 레벨 | 받침대 | 추 종류 | 목표 무게 | par |
|---|---|---|---|---|---|
| 01 | 첫 균형 | 0 | 1·2·3·5 | 4 | 확정 |
| 02 | 같은 거리 | 0 | 1·2·3·5 | 6 | 확정 |
| 03 | 한쪽으로 | −0.11 | 1·2·3·5 | 6 | 확정 |
| 04 | 긴 팔 | −0.22 | 1·2·3·5 | 8 | 확정 |
| 05 | 큰 추 | 0 | 2·3·5 | 10 | 확정 |
| 06 | 가운데 저울 | 0.11 | 1·2·3·5 | 9 | 확정 |
| 07 | 큰 저울 | −0.22 | 2·3·5 | 12 | 확정 |
| 08 | 최종 저울 | 0 | 1·2·3·5 | 12 | 확정 |

**레벨은 코드로 고정한다.** 각 레벨에 대해
1. 기준 해법이 두 조건을 모두 만족하고,
2. **모든 배치를 열거해** 두 조건을 만족하는 최소 추 개수가 `par` 와 같고,
3. 같은 무게라도 팔 길이가 다른 위치에 놓으면 결과가 달라짐을
단위 테스트가 확인한다.

## 6. 검증 3층

### 1층 — 단위 테스트

| 묶음 | 검증 내용 |
|---|---|
| 모멘트 | 한 개의 추의 모멘트 = m·g·팔길이 · 반대편 추는 부호가 반대 |
| 기울기 | `atan2(Στ, Σm·g)` · 추가 없으면 0 · 기울기는 ±0.6 rad 이내 |
| 무게중심 | `Σ(m·x)/Σm` · 무게중심이 받침대 위치면 수평 |
| 최소 추 열거 | 모든 (홈 × 추 종류) 조합을 돌려 최소 개수 = par |
| 레벨 | 8종 모두 기준 해법이 두 조건 달성 · 최소 개수 == par |

### 2층 — 기하 불변식 (0.5초마다)

모든 추의 위치 유한 · 저울판 회전각 == 계산한 기울기 ±1e-9 ·
추가 판의 홈 위에 있음 · 모멘트 합이 유한 · 추 개수 == 놓인 개수

### 3층 — 화면 판정

4시점 캡처 · 콘솔 오류 0 · 자동 조작 `__gameApi.solve()` (기준 해법 배치 → 결과 팝업) ·
모바일 390×844 HUD 겹침 0

## 9. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 추가 빠지면 기울기가 남아 보인다 | 추가 놓을 때마다 상태를 다시 계산(파생 상태는 항상 갱신) |
| 같은 총 무게라도 팔 길이가 다르면 결과가 다르다 | 레벨 설계에서 같은 무게·다른 팔 길이 조합을 테스트로 고정 |
| 기울기 각도가 화면과 어긋난다 | 2층 불변식이 회전각과 계산값을 1e-9로 대조 |
| 최소 개수가 손맛 파라미터가 된다 | 전수 열거로 계산하고 par 와 대조 |
