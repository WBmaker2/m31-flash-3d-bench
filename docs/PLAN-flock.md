## 1. 왜 이 게임인가 — 기존 7종과 축 분리

| 게임 | 검증하는 능력 |
|---|---|
| `zoo/` | 절차적 지오메트리 조립 + 애니메이션 |
| `molecule/` | 클릭 상호작용 + 화학 규칙 + 판정 |
| `defense/` | 실시간 상태 머신 + 경로 + 전투 |
| `shapes/` | 3D 회전 + 격자 배치 + 형상 판정 |
| `ballistics/` | 수치 적분 + 연속 충돌 + 조준 |
| `robot/` | 역기구학 + 관절 체인 + 링크 충돌 |
| `maze/` | 1인칭 카메라 + 절차 생성 + 최단 경로 탐색 |

**이번에 새로 검증하는 능력**

1. **다체 에머전트 행동** — 분리(separation) · 정렬(alignment) · 응집(cohesion)
2. **스티어링(steering) 합성** — 규칙 벡터를 더하고 힘으로 제한해 속도를 바꾼다
3. **이웃 탐색** — 반경 안의 이웃을 찾아 규칙을 계산한다
4. **群体的 지표** — 중심 · 평균 속도 · 흩어짐
5. **선분-평면 교차 판정** — 링 게이트 통과 여부

**에머전트 행동은 "그냥 잘 보이면" 통과시킬 수 없다.** 이 게임은 각 규칙의 성질을
숫자로 증명하는 테스트를 먼저 쓴다.

## 2. 게임 정의

**핵심 루프**: 플레이어가 "불빛"(공짜 목표)을 움직여 새 떼를 링 게이트들을 차례로
통과시킨다. 떼를 흩뜨리지 않고 몰수록 별점이 오른다.

- **무리**: 새 120~400마리. 각 새는 Reynolds 의 세 규칙에 더해 불빛을 따라간다
- **플레이어**: WASD 로 불빛을 움직인다. 마우스로 카메라를 돌려 무리를 지켜본다
- **게이트**: 떠 있는 링. 순서대로 통과해야 다음 게이트가 켜진다
- **흩어짐**: 떼가 흩어지는 정도(중심에서 평균 거리). 불빛을 급하게 흔들면 커진다
- **판정**: 모든 게이트 통과 = 클리어. 제한 시간을 넘기면 실패. 통과한 게이트 수 ·
  남은 시간 · 흩어짐으로 별 3/2/1

## 3. 수치 계약

## 6. 검증 3층

### 1층 — 단위 테스트 (44개)

| 묶음 | 검증 내용 |
|---|---|
| 이웃 | 반경 안/밖 정확히, 자기 자신 제외 |
| 분리 | 가까운 두 개체가 서로 밀어남(거리가 증가) |
| 정렬 | 이웃이 같은 방향이면 그 방향을 향함 |
| 응집 | 무리 중심을 향함 |
| 속도 | 최대·최소 속도를 넘지 않음 |
| dt 독립성 | dt/2 로 두 번 vs dt 로 한 번 → 위치 오차 허용 범위 |
| 결정론 | 같은 입력 → 같은 출력 |
| 경계 | 경기장 밖으로 나가지 않음 |
| 게이트 | 평면 통과 + 반경 안이면 통과, 반경 밖이면 미통과, 평행이면 미통과 |
| 지표 | 중심 · 평균속도 · 흩어짐 정확성 |
| 판정 | 별점 구간, 시간 초과 실패 |

### 2층 — 기하 불변식 (0.5초마다)

개체 수 유지 · 위치·속도 유한 · 속도 상한 · 경기장 안 · 흩어짐 유한

### 3층 — 화면 판정

4시점 캡처 + 콘솔 오류 0. 자동 검사 단계는 `__gameApi.solve()`(불빛을 게이트 순서대로
자동 이동해 통과시킴) → 결과 팝업 캡처.

## 9. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 400마리 × 이웃 탐색 성능 | 400² = 16만 거리 검사/스텝. JS 에서 프레임당 2 ms 내외. 부족하면 공간 해시로 교체(순수 함수로 검증 가능) |
| 행동 규칙 튜닝이 지루함 | 규칙별 성질(분리 시 거리가 늘어난다 등)을 테스트로 고정 |
| 흩어짐 수치가 흔들림 | 지표는 지수 이동 평균으로 평활화 |
| 게이트 통과 판정이 어긋남 | 선분-평면 교차 + 반경 검사로 정확히 판정 |
| 게임이 지루함 | 시간 제한 + 흩어짐 제한 + 게이트 순서로 긴장감 부여 |
| 모듈 수 증가 | 모듈 7개 이내, 도메인 로직 250줄 이내 |
