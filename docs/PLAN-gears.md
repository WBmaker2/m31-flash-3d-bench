## 1. 왜 이 게임인가 — 기존 9종과 축 분리

| 게임 | 검증하는 능력 |
|---|---|
| `zoo/` | 절차적 지오메트리 조립 + 애니메이션 |
| `molecule/` | 클릭 상호작용 + 화학 규칙 + 판정 |
| `defense/` | 실시간 상태 머신 + 경로 + 전투 |
| `shapes/` | 3D 회전 + 격자 배치 + 형상 판정 |
| `ballistics/` | 수치 적분 + 연속 충돌 + 조준 |
| `robot/` | 역기구학 + 관절 체인 + 링크 충돌 |
| `maze/` | 1인칭 카메라 + 절차 생성 + 최단 경로 |
| `flock/` | 다체 에머전트 행동 + 이웃 탐색 |
| `sculpt/` | 암시적 곡면(SDF) + CSG + 등표면 메시 추출 |

**이번에 새로 검증하는 능력**

1. **회전 동역학** — 각속도가 링크(기어비)를 따라 전파된다. 앞의 9종엔 "회전이 다른 회전을
   만든다"는 관계가 없다.
2. **비부호 링크비** — 맞물린 기어는 **반대 방향**으로 돈다. 부호가 빠진 채점과 반대다.
3. **위상(phase) 보존** — 맞물린 두 기어는 `θ₁·N₁ + θ₂·N₂` 가 일정하다. 회전 위상이
   어긋나면 톱니가 서로 파먹는다. 이 불변식은 화면으로 안 보인다.
4. **비정상 조합 탐지** — 홀수 개의 기어가 고리로 맞물리면 회전할 수 없다(비-consistent).
   게임은 이런 조합을 "같은 값을 두 경로에서" 돌리지 않고 **오류로 표시**한다.
5. **주어진 크기에 맞는 배치** — 크기가 다른 기어는 슬롯마다 들어갈 수 있는지가 달라진다.

**판정이 "잘 보이면"이 아니라 숫자다.** 기어비·속도·방향·위상을 모두 1e-9 오차로 고정한다.

## 2. 게임 정의

**핵심 루프**: 나무 판에 꽂힌 톱니바퀴에 크기를 골라 끼운다. 손잡이 톱니바퀴를 돌리면
맞물린 톱니가 **비율만큼 빠르게, 반대 방향으로** 돈다. 미션(예: "미션 톱니가 초당 1.5바퀴")
을 맞추면 별을 받는다.

- **플레이어 조작**
  - 팔레트에서 톱니 수 선택(8 · 12 · 16 · 20 · 24) → 빈 슬롯 클릭 → 그 크기로 끼운다
  - 끼운 톱니 클릭 → 뺀다(팔레트로 돌아간다)
  - 슬롯은 판에 박혀 있다. **크기가 다르면 들어가지 않는다**(겹침).
  - 크랭크(입력 톱니바퀴)는 항상 회전한다. 슬롯 위치가 정해져 있으므로 **어느 길로
    연결할지**가 곧 퍼즐이다.
- **판정**: 미션 슬롯의 실측 속도(±허용) + 회전 방향(같음/반대) + 사용 기어 수(par)
- **별점**: 별3 = 미션 달성 + 기어 수 ≤ par · 별2 = 미션 달성 · 별1 = 속도만 일치 ·
  별0 = 미시
- **레벨**: 8종. 목표값은 **기준 해법의 실측값**이라 항상 달성 가능하다
  (`maze/`의 par = BFS 최적 경로, `sculpt/`의 목표 IoU = 기준 해법 실측과 같은 원칙).
- **추가 규칙**: 기어 수는 par 이하여야 3성. par 은 **최소 기어 수**로 정의해
  "아무거나 꽂으면 끝"인 레벨이 없게 한다.

## 3. 수치 계약

| 값 | 값 | 단위 |
|---|---|---|
| 톱니 모듈 | 0.02 | m (톱니 한 개의 크기) |
| 피치 반지름 | `N × 0.01` | m (N = 톱니 수) |
| 톱니 수 종류 | 8 · 12 · 16 · 20 · 24 | 개 |
| 입력(크랭크) 속도 | 1.0 | 회전/초 |
| 메시 판정 허용 오차 | 1e-6 | m |
| 겹침 판정 허용 오차 | 1e-6 | m |
| 속도 판정 허용 오차 | 0.01 | 회전/초 |
| 위상 불변량 | `θ₁·N₁ + θ₂·N₂` | rad (변화 ≤ 1e-9) |
| 시뮬레이션 시간 | 3.0 | s (위상 검사용) |

### 기어비 규칙

맞물린 두 기어 A, B 에 대해

```
ω_B = −ω_A × (N_A / N_B)      (부호 반전 + 톱니 수 역비)
θ_B = −θ_A × (N_A / N_B)
```

`ω` 는 rad/s, `θ` 는 rad. **1단 연결은 반대 방향, 2단은 같은 방향.**

## 4. 레벨 8종

기하(슬롯 좌표)는 손으로 설계하되, **모든 값은 스크립트로 열거해 확인한다.**

| # | 레벨 | 크랭크 톱니 | 슬롯 | 미션 | par |
|---|---|---|---|---|---|
| 01 | 첫 톱니 | 12 | 2 | 미션 톱니가 초당 1.5회, 반대 방향 | 1 |
| 02 | 느린 톱니 | 8 | 3 | 초당 0.5회 이하? (아래 확정) | 확정 |
| 03 | 3배 속도 | 24 | 3 | 초당 3회, 반대 방향 | 1 |
| 04 | 두 번 연결 | 12 | 4 | 초당 1회, 같은 방향 | 2 |
| 05 | 긴 길 | 16 | 5 | 확정 | 확정 |
| 06 | 역회전 | 12 | 4 | 반대 방향 | 확정 |
| 07 | 적은 기어 | 20 | 5 | 확정 | 확정 |
| 08 | 바람개비 | 24 | 6 | 확정 (마지막) | 확정 |

**레벨은 코드로 고정한다.** 각 레벨에 대해
1. 기준 해법(`reference`)이 미션을 달성하고,
2. **모든 배치(5^N)를 열거해** 미션을 달성하는 최소 기어 수가 `par` 와 같고,
3. 기준 해법 밖의 의도치 않은 메시가 생기지 않음을
단위 테스트가 확인한다. (값은 계획 단계에서 스크립트로 확정해 문서에 적는다.)

테스트된다.

## 6. 검증 3층

### 1층 — 단위 테스트

| 묶음 | 검증 내용 |
|---|---|
| 반지름·비율 | `r = N × 0.01` · `N` 에 선형 · 비율이 역수 관계 |
| 메시 판정 | 거리가 `r₁+r₂` 와 같을 때만 메시 · 1e-6 밖이면 아님 |
| 겹침 판정 | 거리 < `r₁+r₂` 면 겹침 · 끼울 수 없음 |
| 회전 전파 | 1단 부호 반전 · 2단 부호 유지 · `ω_B = −ω_A·N_A/N_B` ±1e-9 |
| 경로 | 크랭크와 연결 안 된 기어는 `ω = 0` |
| 고리 | 홀수 고리(3기어)는 **비-consistent** 로 탐지 · 짝수 고리는 비율 모순 없음 |
| 위상 | 3초 회전 후 모든 메시 쌍의 `θ₁N₁+θ₂N₂` 변화 ≤ 1e-9 |
| 레벨 | 8종 모두 기준 해법이 미션 달성 · 최소 기어 수 == par · 의도치 않은 메시 0 |

### 2층 — 기하 불변식 (0.5초마다)

모든 각도·각속도 유한 · 모든 메시 쌍의 거리 오차 < 1e-6 · 겹치는 기어 0 ·
위상 불변량 변화 ≤ 1e-9 · 미션 슬롯의 톱니가 존재

### 3층 — 화면 판정

4시점 캡처 · 콘솔 오류 0 · 자동 조작 `__gameApi.solve()` (기준 해법 배치 → 미션 달성 →
결과 팝업) · 모바일 390×844 HUD 겹침 0

## 9. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 톱니 형상이 어긋나 보임 | 톱니 각도 fraction을 상수로 정의하고, 피치 원주 길이 = 모듈이 되도록 검증 |
| 기어가 겹쳐 보임 | 배치 규칙 자체가 겹침 금지. 불변식이 매 프레임 검사 |
| 위상이 어긋나 톱니가 깨져 보임 | 위상 불변량을 1층 테스트와 2층 불변식이 동시에 검사 |
| 고리 조합에서 회전이 안 돌면 | 비-consistent 조합을 오류로 표시(무한 회전 금지) |
| 레벨이 너무 쉽거나 불가능 | 모든 배치를 열거해 최소 기어 수를 계산하고 par 과 대조 |
| 점수가 화면과 어긋남 | 미션 판정은 회전 전파 결과 하나에서만 나온다 |
