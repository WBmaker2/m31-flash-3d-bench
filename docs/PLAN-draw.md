# 구현 계획 — 18번째 3D 게임 `draw/` (3D 그림 그리기)

- 작성일: 2026-10-24
- 선행 계획: [`PLAN.md`](PLAN.md), [`GAME-IDEAS.md`](GAME-IDEAS.md)

## 1. 왜 이 게임인가 — 기존 17종과 축 분리

앞의 17종은 지오메트리 조립·화학 규칙·상태 머신·격자 배치·수치 적분·역기구학·최단 경로·
에머전트 행동·암시적 곡면·회전 동역학·표면 셀 그래프·시드 난수·역학 평형·캐릭터 물리·
기하 광학·전개도 접기·조각 연결까지 다뤘다. **아직 검증하지 않은 축**은 "자유 배치와
 스냅샷 비교" 이다.

1. **픽셀 그림 해석** — 문자 배열을 칸 목록과 색 목록으로 바꾸기
2. **자유 배치** — 칸마다 큐브를 놓고 지울 수 있다(정답이 정해져 있지 않다)
3. **스냅샷 비교** — 목표 그림과 놓인 큐브를 칸 단위로 대조
4. **오염 지표** — 목표에 없는 칸을 잘못 놓은 개수

`paint/`(11번째)는 "flood fill 로 영역을 칠하는" 게임이었다. 이 게임은 "칸을 하나씩
놓는" 자유 배치라 조작 축이 다르다.

## 2. 게임 정의

**핵심 루프**: 목표 그림(픽셀 아트)을 보고 판 위에 큐브를 하나씩 올려 그림을 그대로 만든다.

- **조작** — 색 고르기 → 빈 칸 클릭(큐브 놓기) → 다시 클릭(지우기)
- **판정** — 맞은 칸 비율(일치율 %) + 잘못 놓은 칸 수
- **별점** — 별3 = 일치율 100% + 잘못 놓은 칸 0 · 별2 = 일치율 100% · 별1 = ≥ 50% ·
  별0 = 실패
- **레벨** — 8종. 하트 · 해바라기 · 집 · 나무 · 고양이 · 우주선 · 꽃 · 별

## 3. 수치 계약

| 값 | 값 | 단위 |
|---|---|---|
| 한 칸 | 0.2 | m |
| 그림 크기 | 6×6 ~ 10×10 | 칸 |
| 색 종류 | 그림마다 1 ~ 3 | 종 |
| 일치율 | 맞은 칸 / 목표 칸 | — |
| 잘못 놓은 칸 | 목표 밖이거나 색이 다른 칸 | 개 |

### 비교 규칙

```
맞은 칸   = 목표 칸에 같은 색으로 놓인 칸
잘못 놓은 칸 = 목표에 없거나 색이 다른 칸
일치율 = 맞은 칸 / 목표 칸 수
```

## 4. 레벨 8종

| # | 레벨 | 크기 | 색 | 칸 수 |
|---|---|---|---|---|
| 01 | 하트 | 6×6 | 1 | 24 |
| 02 | 해바라기 | 8×8 | 2 | 48 |
| 03 | 집 | 10×8 | 3 | 60 |
| 04 | 나무 | 10×8 | 2 | 44 |
| 05 | 고양이 | 10×8 | 2 | 44 |
| 06 | 우주선 | 10×8 | 4 | 46 |
| 07 | 꽃 | 8×8 | 2 | 44 |
| 08 | 별 | 9×9 | 1 | 41 |

**레벨은 코드로 고정한다.** 각 레벨에 대해
1. 그림을 해석하면 칸이 하나 이상 나오고,
2. 쓰인 색이 있고,
3. 목표대로 놓으면 일치율 1 이며,
4. 색을 틀리게 놓으면 맞은 칸으로 세지 않는 것을 단위 테스트가 확인한다.

## 6. 검증 3층

### 1층 — 단위 테스트
그림 해석(크기·칸 수·빈 칸 제외) · 쓰인 색 · 빈 배치 0 · 완전 일치 1 ·
색이 틀리면 불일치 · 목표 밖 칸은 잘못 놓은 칸 · 레벨 8종 구조 · 별점 규칙

### 2층 — 기하 불변식 (0.5초마다)
좌표·색 유한 · 일치율 0~1 · 맞은 칸 수 범위 · 잘못 놓은 칸 수 ≥ 0
