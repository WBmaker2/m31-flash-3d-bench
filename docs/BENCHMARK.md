# 벤치마크 보고서 — M3.1 Flash의 three.js 3D 구현

- 기준일: 2026-10-25
- 대상 모델: `opencode/minimax-m3.1-flash-free` (README 표기: MiniMax M3.1 Flash)
- 범위: 이 저장소의 게임 18종
- 증거: `*/src/*.test.js`, `*/src/invariants.js`, `docs/checks.json`, `docs/shots/`, `docs/baseline/`

## 1. 이 보고서를 읽는 법

이 저장소는 "게임이 재미있는가"보다 **모델이 3D 구현의 어떤 부분을 해내고 어디서 조용히 틀리는가**를 남기는 것이 목적입니다.
그래서 게임별로 ① 검증한 능력 ② 수치로 고정한 계약 ③ 실제로 드러난 실패 ④ 화면 증거를 함께 적습니다.

| 층 | 확인하는 것 | 실행 |
|---|---|---|
| 1층 순수 계산 | 수식·상태·판정이 맞는가 | `npm test` |
| 2층 기하 불변식 | 런타임에 항상 참이어야 하는가 | `npm run qa` |
| 3층 화면 판정 | 값이 맞아도 화면에 보이는가 | `npm run qa` · `npm run qa:visual` |
| UI 계약 | 공용 스타일·백링크·터치 영역·랜딩 수치가 맞는가 | `npm run qa:ui` |

## 2. 능력 축과 게임

| 게임 | 검증 축 | 수치 계약의 예 |
|---|---|---|
| `zoo` | 절차적 지오메트리 + 애니메이션 | 표면 돌출량, 개체 간 거리 |
| `molecule` | 클릭 상호작용 + 화학 규칙 | 결합각 104.5° ± 0.5°, 이웃 다중집합 |
| `defense` | 실시간 상태 머신 + 경로 | 경로 길이, 타워 사거리, 별점 |
| `shapes` | 3D 회전 + 격자 배치 | 24회전군, 칸 단위 일치 |
| `ballistics` | 수치 적분 + 연속 충돌 | 해석해 대비 1e-9, 예측 궤적 == 실제 궤적 |
| `robot` | 역기구학 + 관절 체인 | `forwardArm(solveArm(t))` 오차 1e-9 |
| `maze` | 1인칭 + 절차 생성 + 최단 경로 | par = BFS 최적 경로 |
| `flock` | 다체 에머전트 행동 | 규칙별 수치 성질, 평형 흩어짐 |
| `sculpt` | SDF + CSG + 등표면 메시 | 실루엣 IoU, 부호 체적, 맨폴드 |
| `gears` | 회전 동역학 + 기어비 | 각속도 ±1e-9, `θ₁N₁ + θ₂N₂` 불변 |
| `paint` | 표면 셀 그래프 + flood fill | 일치율 %, 최소 클릭 수 |
| `dice` | 시드 난수 + 자세→면 매핑 | 기대값 3.5 ± 0.15, 면 일치 |
| `balance` | 모멘트 + 무게중심 | `atan2(Στ, Σmg)` ±1e-9 |
| `cloud` | 캐릭터 컨트롤러 + 스윕 착지 | 스텝 크기 무관 착지 |
| `laser` | 기하 광학 | 반사각 ±1e-12, par |
| `net` | 전개도 접기 | 6면 비겹침, 정답 유일성 |
| `rail` | 포트 연결 + 경로 탐색 | 최단 경로, par |
| `draw` | 자유 배치 + 스냅샷 비교 | 일치율 %, 잘못 놓은 칸 |

## 3. 현재 수치

- 게임: 18종
- 단위 테스트: 615개 (게임 448 + 공통 167)
- QA 화면: 게임별 4시점 캡처 + 대표 조작 + 모바일 390×844
- 콘솔 오류: 0건 (커밋된 `docs/checks.json` 기준)
- 불변식 위반: 0건
- 카드 이미지: 54장 (3시점 × 18)

`docs/checks.json`의 값은 랜딩에 그대로 표시되고, `npm run qa`가 실제 값과 대조합니다.

## 4. 반복해서 나온 실패 유형

| 유형 | 사례 | 잡은 방법 |
|---|---|---|
| 좌표·배치가 상태 갱신에 묶임 | 동물이 정지 상태에서 원점에 겹침 | 정지 상태 유닛 테스트 + 개체 거리 불변식 |
| 표면 밖/안쪽 계산 | 판다 눈·귀가 머리 안에 파묻힘 | 돌출량 테스트 + 표면 밖 불변식 |
| 단위 혼용 | 결합각 도/라디안 혼용으로 180° | 단위 계약 테스트 |
| 카메라와 무관한 판정 | 분자가 옆으로 누워 안 읽힘 | 시선 각도 테스트 + 4시점 캡처 |
| 경계 부동소수점 | 구-상자 접촉 판정 흔들림 | 경계 여유 1e-9 + 경계 테스트 |
| 두 경로의 값 불일치 | 예측 궤적과 실제 궤적 | 같은 함수(`simulateFlight`) 사용 |
| NaN이 조용히 전파 | SDF 인자 누락 | 모든 값 유한성 테스트 |
| 화면과 계산의 분리 | 기어 톱니 위상, 주사위 자세 | 런타임 불변식 + 1층 테스트 |
| UI 통합 누락 | 공용 팝업 스타일 미적용, iframe 백링크 | `qa:ui` + 팝업 스모크 |
| 모바일 입력 누락 | 키보드 전용 게임 3종 | 터치 패드 + 모바일 버튼 검사 |

## 5. 점수 rubric (제안)

| 항목 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 계산 정확성 | 실패 | 일부 통과 | 핵심 계약 통과 | 경계·불변식까지 통과 |
| 화면 판독성 | 안 보임 | 한 시점만 | 4시점 | 4시점 + 모바일 |
| 상호작용 | 불가 | 일부 | 키보드/마우스 | 키보드·마우스·터치 |
| 유지보수 | 단일 파일 | 분리 | 공용 계층 | 공용 계층 + 계약 검사 |

현재 18종은 "계산 정확성 3, 화면 판독성 3"에 가깝고, **상호작용·유지보수는 게임별 편차**가 있습니다.
다음 평가에서는 이 rubric으로 게임별 점수를 매겨 `docs/checks.json`과 별도로 기록하는 것을 권장합니다.

## 6. 한계

- 모델의 프롬프트·시도 횟수는 아직 게임별로 구조화되어 있지 않습니다. `docs/RUNS.md`에 누적합니다.
- "재미"와 "교육 효과"는 자동 검사로 측정하지 않습니다. 별도 사용자 평가가 필요합니다.
- 화면 판정은 픽셀·투영 좌표 기반이라 의미론적 오류(예: 잘못된 한글 문구)를 잡지 못합니다.
- QA는 최신 Chromium 기준입니다. 학교 구형 기기·Safari는 별도 확인이 필요합니다.
