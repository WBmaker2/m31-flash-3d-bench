**이번에 새로 검증하는 능력**

1. **시드 난수 결정론** — 같은 시드면 굴림 결과가 언제나 같다. 주사위는 굴리는 데
   물리 시뮬레이션을 하지 않는다. **결과를 정하고 그 결과에 맞는 자세로 멈추게** 만든다.
2. **자세 → 면 매핑** — 주사위가 실제로 어느 면을 위로 향해 멈췄는지(3D 자세)를 숫자로 읽어
   "몇이 나왔는지"와 대조한다. 화면에 6이라고 적혀 있는데 자세는 3을 향하면 **오류**다.
3. **턴 상태 머신** — 두 플레이어의 차례가 번갈아 가고, 점수와 승패 전이가 모순 없이 이어진다.
4. **보드 경로** — 뱀과 사다리판에서 말이 정확히 n칸씩 이동하고, 뱀·사다리는 한 번에 옮겨진다.
5. **기대값** — 주사위가 공정하다는 것을 수치로 확인한다(600회 평균 3.5 ± 0.15).

## 2. 게임 정의

**핵심 루프**: 주사위를 굴리면(1~6) 말이 그만큼 칸 앞으로 간다. 뱀과 사다리를 타고
넘어갈 수도 있다. 도착한 칸에서 **더하기 문제**가 나오면 맞혀서 점수를 얻는다.
먼저 결승점에 도착한 사람이 이긴다.

- **플레이어 조작**
  - **굴리기 (Space)** — 주사위가 굴러 멈추고 말이 이동한다
  - **정답 고르기** — 더하기 문제의 보기 3개 중 하나를 누른다
  - 정답이면 +1칸 더 가고 점수를 얻는다
- **판정**: 승리 도달 여부 + 맞힌 문제 수(점수)
- **레벨**: 보드 3종(기본 · 뱀 사다리 · 긴 보드). 각 보드는 다른 칸 수와 다른 점프를 가진다
- **추가 규칙**: 주사위 값·정답·질문은 모두 시드 난수로 정해지므로 같은 시드면 같은 게임이 된다

## 3. 수치 계약

| 값 | 값 | 단위 |
|---|---|---|
| 주사위 면 | 1 ~ 6 | — |
| 면 배치 | 1↔6 · 2↔5 · 3↔4 (마주 보는 면의 합은 7) | — |
| 주사위 한 변 | 0.09 | m |
| 굴림 애니메이션 | 0.9 | s |
| 말 이동(칸당) | 0.12 | s |
| 말 점프 높이 | 0.09 | m |
| 보드 한 칸 | 0.17 | m |
| 보드 크기 | 5×5 (기본) · 5×6 (긴 보드) | 칸 |
| 기대값 검사 | 600회 평균 3.5 ± 0.15 | — |
| 면별 빈도 | 1/6 ± 0.03 | — |

### 주사위 자세 → 면

주사위의 각 면은 **자기 좌표계의 축**에 붙어 있다.

| 값 | 자기 법선 |
|---|---|
| 1 | +Y |
| 6 | −Y |
| 2 | +X |
| 5 | −X |
| 3 | +Z |
| 4 | −Z |

멈춘 주사위의 **위쪽(+Y) 방향**을 `up` 이라고 할 때, `dot(up, 법선)` 이 가장 큰 면이
위에서 보이는 면이다. 굴림 애니메이션은 이 값이 **정답 면**과 같아지는 자세로 끝난다.

## 4. 보드 3종

| # | 보드 | 크기 | 칸 수 | 점프 |
|---|---|---|---|---|
| 01 | 첫 보드 | 5×5 | 25 | 사다리 1 · 뱀 1 |
| 02 | 뱀과 사다리 | 5×6 | 30 | 사다리 3 · 뱀 3 |
| 03 | 긴 보드 | 6×6 | 36 | 사다리 4 · 뱀 4 |

경로(칸 순서)는 지그재그( serpenteine )로 **코드로 생성**한다. 점프 표는 레벨 데이터에 있고,
점프는 **한 번만** 적용된다(사다리를 타고 또 사다리를 타지 않는다).

보드 계산은 여기 남겨 다음 게임이 물려받는다.

## 6. 검증 3층

### 1층 — 단위 테스트

| 묶음 | 검증 내용 |
|---|---|
| 난수 결정론 | 같은 시드 → 같은 수열 100회 · 다른 시드 → 다른 수열 |
| 주사위 공정성 | 600회 평균 3.5 ± 0.15 · 면별 빈도 1/6 ± 0.03 |
| 자세 → 면 | 위쪽 벡터에서 면이 정확히 읽힘 · 마주 보는 면의 합은 7 |
| 보드 경로 | 칸 수 = 가로×세로 · 경로가 모든 칸을 한 번씩 지남 · 인접 칸이 실제로 맞닿음 |
| 이동 | n칸 이동 후 위치가 정확히 n칸 · 점프는 한 번만 · 결승점을 넘어가면 끝 |
| 질문 | 답이 정답 · 보기 3개가 서로 다름 · 같은 시드면 같은 질문 |

### 2층 — 기하 불변식 (0.5초마다)

주사위 자세에서 읽은 면 == 화면에 보고 있는 값 · 말의 위치 == 경로 인덱스의 칸 좌표 ·
두 말의 위치가 다름 · 모든 좌표 유한 · 주사위 값 1~6

### 3층 — 화면 판정

4시점 캡처 · 콘솔 오류 0 · 자동 조작 `__gameApi.solve()` (굴리기 → 이동 → 정답 → 다음 턴) ·
모바일 390×844 HUD 겹침 0

## 9. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 굴림 애니메이션이 면 값과 어긋남 | 1층 테스트와 2층 불변식이 자세→면을 대조 |

| 말이 칸 사이에 멈춤 | 말의 위치는 경로 인덱스로만 정하고 좌표는 거기서 뽑는다 |
| 점프가 연쇄됨 | 점프는 한 번만 적용한다(테스트로 고정) |
| 결승점을 넘어감 | 마지막 칸에 닿으면 그 자리에서 끝난다 |
| 모바일에서 보드가 안 보임 | 카메라가 보드 크기에 맞춰 자동 조절 |
