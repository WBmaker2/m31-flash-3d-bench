# 3D 형태 공방

구·박스·토러스·캡슐을 작업대 위에 놓고 **합·교·차** 연산을 이어 붙여,
반투명으로 비친 목표 형태와 최대한 닮게 만드는 조각 게임입니다.
표면을 좌표가 아니라 **함수**(부호거리장)로 정의하기 때문에,
"닮았는지"를 눈이 아니라 **실루엣 일치도(IoU)** 숫자로 판정합니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/sculpt/
```

## 조작

- **작업대 클릭** — 고른 기본형을 그 자리에 놓습니다
- **부품 드래그** — 부품을 옮깁니다
- **1~4** — 구 · 박스 · 토러스 · 캡슐
- **Q W E** — 합 · 교 · 차 (바닥 순서대로 쌓입니다)
- **[ ]** — 선택한 부품 회전 · **- =** — 크기
- **Delete** — 부품 삭제 · **Ctrl+Z** — 되돌리기
- **G** — 목표 고스트 켜기/끄기 · **R** — 레벨 처음부터
- **Space** — 채점

## 규칙

- 목표는 반투명 고스트로 보입니다. 고스트와 자기 조각이 겹치도록 크기와 위치를 맞춥니다
- **실루엣 일치도**는 정면·옆 두 시점의 IoU 평균입니다. 화면을 돌려도 값이 바뀌지 않습니다
- **부피**도 함께 봅니다. 실루엣이 맞아도 부피가 20% 이상 차이 나면 통과하지 못합니다
- 별점은 일치도 0.94 / 0.88 / 0.80 입니다
- 레벨마다 **목표값**이 있습니다. 그 값은 *기준 해법으로 실제로 얻는 값*이라 항상 달성 가능합니다

## 설계 메모

- **표면을 함수로 정의합니다.** 앞의 8개 게임은 전부 정점 좌표를 직접 썼습니다.
  이 게임은 `sdf(x) = 0` 을 만족하는 점들의 집합이 표면입니다.
  그래서 "이 형태가 저 형태와 얼마나 닮았나"를 같은 함수 두 개로 비교할 수 있습니다.
- **점수는 카메라와 무관합니다.** 채점용 직교 카메라(정면·옆)를 따로 고정하고
  CPU 레이캐스팅으로 계산합니다. 화면을 돌려도 점수가 흔들리지 않습니다.
- **메시 추출은 마칭 테트라히드라.** 256칸짜리 표 대신 여섯 개의 사면체로 잘라
  처리합니다. 48³ 격자에서 부피 오차가 0.5% 안쪽입니다.
- **방향 오류는 부호 체적으로 잡습니다.** 표면이 바깥을 향하면 부호 체적이 양수,
  뒤집히면 음수입니다. 숫자 하나로 메시 방향을 검사합니다.
- **맨폴드도 검사합니다.** 모든 간선이 정확히 두 번 쓰여야 물구멍이 없습니다.
- **목표값은 기준 해법의 실측값입니다.** 손맛 파라미터가 생기지 않습니다
  (`maze/` 의 par = BFS 최적 경로와 같은 원칙).
- **대상어는 목표만 씁니다.** 라운드 박스·타원체·매끈한 합은 목표에만 있어서
  플레이어는 기본형으로 근화해야 합니다.
