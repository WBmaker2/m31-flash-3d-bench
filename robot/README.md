# 3D 로봇 팔 조립실

작업대 위 자리를 누르면 로봇 팔이 **역기구학으로 관절 각을 직접 계산**해 블록을 집어
옮겨 놓는 3D 조립 게임입니다. 배치한 오차(목표 중심으로부터의 거리)를 판정합니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/robot/
```

## 조작

- **작업대 위 클릭** — 블록을 놓을 위치를 정합니다. 위치가 곧 조준 목표가 됩니다
- **R** — 다시 시도 (블록을 장작대로 되돌립니다)
- **레벨 선택** — 레벨 창
- **드래그 · 휠** — 시점 회전과 확대

## 규칙

- 파란 판이 목표입니다. 판의 **가운데에 가까울수록** 정확합니다 (허용 오차는 레벨마다 달라집니다)
- 회색 판은 도달 반경 밖입니다. 손이 닿지 않으므로 손대지 마세요
- 금빛 링이 발사대의 도달 반경입니다
- **기둥**이 있으면 같은 목표에 대해 팔꿈치를 접는 해가 두 개입니다. 팔은 기둥에 막히지 않는 쪽을 고릅니다
- 클리어하면 결과 팝업에 **다음 단계** 버튼이 뜹니다. 펄스로 표시되며 누르면 다음 레벨로 이어집니다

## 구조

| 파일 | 역할 |
|---|---|
| `src/ik.js` | 2절 역기구학 · 정방향 키네마틱 · 링크 세그먼트 · 기둥 충돌 · 배치 계획 (순수 함수, three 불필요) |
| `src/levels.js` | 레벨 8종 (표적 · 장애물 · 허용 오차) + 배치 오차 판정 (순수 함수) |
| `src/arm.js` | 로봇 팔 메시 조립과 관절 회전 |
| `src/stage.js` | 렌더러 · 작업대 · 도달 반경 링 · 카메라 · 고정 스텝 루프 |
| `src/invariants.js` | 기하 불변식 (관절 각 유한 · 도달 반경 · 링크 관통 · 블록 높이) |
| `src/hud.js` | HTML 연결 |
| `src/main.js` | 상태 머신 (대기 → 집기 → 들기 → 옮기기 → 내려놓기 → 판정) |
| `src/robot.test.js` | 단위 테스트 39개 |

## 설계 메모

- **역기구학은 왕복으로 검증합니다.** `forwardArm(solveArm(t))` 의 끝점이 목표와 오차 1e-9
  안에서 같아야 합니다. 이 한 줄의 테스트가 팔꿈치 해의 부호 오류까지 다 잡습니다.
  (deg/rad 혼동으로 결합각이 180°가 된 실패와 같은 유형입니다)
- **두 해를 다 계산합니다.** 같은 목표에 대해 팔꿈치를 위로 접은 해와 아래로 접은 해가
  생깁니다. 기둥이 있으면 하나만 통과하므로, 팔이 스스로 고릅니다.
- **관절 각은 라디안, 표시는 도**입니다. 함수 이름에 `Deg`/`Rad` 접미사를 붙였습니다.
- **이동은 3단입니다.** 들어 올림 → 장애물 위를 넘는 이동 → 내려놓기. 관절 각을 곧바로
  보간하면 팔이 기둥을 그대로 통과합니다.
- **목표 판이 워크벤치 위에 얹혀** 있으므로 판의 높이와 목표 판 중심의 높이를 같은 공식으로
  계산합니다. 어긋나면 아무리 정확하게 눌러도 오차가 남습니다.
- **레벨마다 해가 있음**을 단위 테스트가 확인합니다. 판이 안 닿는 레벨은 테스트가 먼저 잡습니다.

## 검증

```bash
node ../scripts/shot.mjs robot   # 4시점 캡처 + 자동 판정

```
