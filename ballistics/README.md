# 3D 탄도 타워

방위각·고도각·파워를 정해 발사하고, 중력과 바람을 따라 날아가는 포탄으로 표적 상자를
무너뜨리는 3D 탄도 게임입니다. 밑단을 맞히면 위에 쌓인 상자가 함께 무너집니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/ballistics/
```

## 조작

- **방위 · 고도 · 파워 슬라이더** — 조준값을 정합니다. 고도각 5~80°, 방위각 -45~45°, 파워 6~30 m/s
- **발사 (Space)** — 포탄을 쏩니다. 남은 샷이 하나 줄어듭니다
- **다음 단계** — 단계를 통과하면 결과 팝업에 나타납니다. 누르면 바로 다음 레벨로 넘어갑니다
- **↑↓ / ←→** — 고도각과 방위각을 1°씩 (Shift 를 누르면 5°)
- **R** — 레벨 다시 시작
- **레벨 선택** — 레벨 창
- **드래그 · 휠** — 시점 회전과 확대

## 규칙

- 표적 상자를 **모두** 없애면 클리어입니다. 표적은 2 m 격자에 놓인 2×2×2 m 상자입니다
- 클리어하면 결과 팝업에 **다음 단계** 버튼이 뜹니다. 펄스로 표시되며 누르면 다음 레벨로 이어집니다
- 상자를 맞히면 100점, 그 위에 쌓여 무너진 상자 하나당 60점입니다
- 남은 샷 보너스는 샷당 50점, 표준 샷 수(par) 이하로 클리어하면 별 3개입니다
- 벽은 부술 수 없습니다. 발사체가 막히면 표적에 닿지 못합니다
- 바람은 가속도(m/s²)로 작용합니다. HUD 에 방향과 세기가 표시됩니다

## 설계 메모

- **적분은 일정 가속도 한 스텝을 정확히 푼다.** `v' = v + a·dt`, `p' = p + v·dt + ½a·dt²`
  로 갱신하면 중력만 있을 때 위치가 해석해와 오차 1e-9 안에서 같아지고
  에너지 `v²/2 + g·y` 도 정확히 보존됩니다. 유한차분(대충 증가분을 더하는 방식)으로는
  이게 성립하지 않아 "사거리 v²/g" 같은 기준이 흔들립니다.
- **예측 궤적과 실제 비행은 같은 함수를 씁니다.** `predictTrajectory` 와 발사 직후의
  비행 모두 `simulateFlight` 를 호출합니다. 미리보기와 실제 궤적이 어긋나는 일은
  구조적으로 불가능해집니다.
- **단위는 이름에 명시합니다.** 각도는 deg 로 들어오고 rad 로 계산합니다
  (`directionFromAngles` / `anglesFromDirection`). 분자 결합각에서 deg 와 rad 를 섞어
  180° 로 펴진 적이 있는 저장소에서는 이 구분이 특히 중요합니다.
- **발사 지점은 고정입니다.** 발사구 높이는 1.6 m 로 고정이고 포신만 그 지점을 중심으로
  회전합니다. 조준각이 바뀌어도 탄도 시작점이 흔들리지 않습니다.
- **격자 좌표는 `levels.js` 한 곳에 모읍니다.** 칸 → 월드 변환은 `grid.js` 의 두
  함수만 씁니다. 표적 판정과 렌더링이 서로 다른 좌표계를 쓰지 않습니다.
- **레벨마다 해법이 존재합니다.** 단위 테스트가 각 레벨의 `solution` 조준값으로
  표적을 맞힐 수 있는지 확인합니다. 판이 안 맞는 레벨은 테스트가 먼저 잡습니다.
- **움직이는 표적의 위치는 시각의 함수입니다.** `boxes` 를 배열 대신 함수로 넘길 수
  있어서, 이동 표적과의 충돌은 그 순간의 위치로 판정됩니다.
