# 3D 구름 점프

구름을 밟으며 **뛰어** 동전을 모으고 깃발(결승점)에 도달하는 게임입니다.
왼쪽·오른쪽으로 움직이고 Space 로 뛰어넘습니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/cloud/
```

## 조작

- **← →** (또는 A · D) — 좌우 이동
- **Space** — 점프 · **R** — 처음부터
- 마우스 드래그로 시점 바꾸기

## 규칙

- 구름 사이가 비어 있으면 떨어집니다. 떨어지면 처음 위치로 돌아옵니다
- 동전은 구름 사이 공중에 있어요. 점프해서 모아 보세요
- 깃발에 닿으면 통과입니다. 동전을 전부 모으면 3성
- 레벨마다 구름 간격과 높이 차가 다르고, **전부 넘을 수 있는 거리**로 설계되어 있습니다

## 구조

| 파일 | 역할 |
|---|---|
| `common/parts/platform3d.js` | 중력 · 점프 · 스윕 착지 · 도달 거리 (순수 함수, three 불필요) |
| `src/levels.js` | 레벨 8종 + 도달 가능성 검사 (순수 함수) |
| `src/cloudView.js` | 구름 · 캐릭터 · 동전 · 깃발 |
| `src/stage.js` | 렌더러·조명·하늘·카메라(주체 리그)·고정 스텝 루프 |
| `src/invariants.js` | 기하 불변식 (구름에 박히지 않음 · 낙하 속도 한계) |
| `src/hud.js` | HTML 연결 + 동전 · 진행률 |
| `src/controls.js` | 키보드 입력 해석 |
| `src/main.js` | 상태 머신(입력·물리·낙하·도달) + UI 배선 |
| `common/parts/platform3d.test.js` · `src/levels.test.js` | 단위 테스트 30개 |

## 설계 메모

- **착지는 스윕 판정입니다.** 한 스텝 동안 바닥이 `fromY → toY` 로 내려갈 때
  `fromY ≥ 구름 윗면 ≥ toY` 이면 그 구름 위에 섭니다. 스텝이 커져도 뚫지 않습니다.
- **점프 궤적은 숫자입니다.** 최고 높이 `v²/2g` = 1.36 m, 비행 시간 `2v/g` = 0.78 s,
  도달 거리 `v·2v/g` = 3.58 m. 레벨의 구름 간격과 높이 차를 이 값으로 검사합니다.
- **물리는 고정 스텝으로 돌립니다.** 화면 프레임레이트와 무관하게 같은 결과가 나옵니다.
- **카메라는 주체를 따라가되 사용자의 회전을 지킵니다.** 주체의 이동량만 카메라에
  더해서, 마우스로 돌린 각도가 그대로 유지됩니다.
- **떨어지면 처음 위치로** 돌아옵니다. 실패해도 계속 시도할 수 있습니다.
