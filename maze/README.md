# 3D 미로 탈출

1인칭으로 걸어다니며 열쇠를 모아 문을 열고 출구로 나가는 미로 게임입니다.
걸은 길은 **BFS로 구한 최적 경로**와 비교해 별점이 됩니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/maze/
```

## 조작

- **방향키 · WASD** — 한 칸씩 이동합니다. 벽에 막히면 진행 방향으로 미끄러집니다
- **마우스** — 화면을 둘러봅니다(포인터락)
- **M** — 미로 전체를 내려다보는俯瞰 시점으로 전환합니다
- **R** — 현재 레벨을 다시 시작합니다
- **레벨 선택** — 레벨 창

## 규칙

- 미로는 시드 고정 DFS로 생성됩니다. 같은 레벨은 언제나 같은 미로입니다
- 열쇠를 주우면 대응하는 문이 열립니다. 열쇠는 문을 통과하지 않고도 닿는 곳에 있습니다
- 초록빛 기둥이 출구입니다. 열쇠를 모두 모은 뒤 지나가세요
- **최적 경로 35칸**처럼 기준은 손으로 정하지 않습니다. BFS로 계산한 최단 경로 길이가 그대로 par 입니다
- 결과 화면에 "최적 경로보다 N칸 더 걸었다"고 알려 줍니다

| 파일 | 역할 |

## 설계 메모

- **미로는 완전 미로입니다.** 모든 칸이 연결되고 통로 수가 칸수-1입니다.
  이 성질은 "아무 칸에서 아무 칸으로든 갈 수 있다"를 보장해 막히지 않게 합니다.
- **문은 출구로 가는 길의 마지막 구간에만 놓습니다.** 그러면 열쇠가 항상 문 앞에 모입니다.
  열쇠를 문 뒤에 두면 못 푸는 판이 생깁니다.
- **최단 경로는 (위치 × 획득 열쇠) 상태 공간에서 BFS로 구합니다.** 열쇠를 안 들고 출구로
  갈 수 없는 경우까지 정확히 계산합니다. par 은 이 값이므로 손맛이 없습니다.
- **대조 구현으로 검증합니다.** 테스트에서 BFS를 따로 한 번 더 짜서 두 구현의 걸음 수를
  비교합니다. 한쪽만 맞으면 둘 다 틀릴 수 있습니다.
- **포인터락은 직접 구현했습니다.** 벤더에 `OrbitControls` 만 있고, 리그(요·피치)와
  자유 시점 전환을 함께 제어해야 해서 외부 애드온에 기대지 않았습니다.
- **검사용 시점은 리그를 덮어씁니다.** 1인칭 조작과 4시점 자동 검사가 서로 간섭하지
  않도록 모드를 나눴습니다.

## 검증

```bash
node ../scripts/shot.mjs maze   # 4시점 캡처 + 자동 판정
npx vitest run maze             # 단위 테스트 34개
```
