# 3D 그림 그리기

목표 그림(픽셀 아트)을 보고 판 위에 큐브를 하나씩 올려 **그림을 그대로** 만드는 게임입니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/draw/
```

## 조작

- **색 고르기** — 팔레트에서 색을 고릅니다
- **빈 칸 누르기** — 큐브를 놓습니다 · 다시 누르면 지웁니다
- **R** — 판 비우기 · 마우스 드래그로 시점 바꾸기

## 규칙

- 왼쪽 위 패널에 목표 그림이 보여요
- **일치율**은 목표 칸 중 같은 색으로 맞힌 비율입니다
- 목표에 없는 칸에 놓으면 **잘못 놓은 칸**이 됩니다
- 별점은 일치율 100% 이고 잘못 놓은 칸이 없을 때 3성입니다

## 구조

| 파일 | 역할 |
|---|---|
| `common/parts/draw3d.js` | 픽셀 그림 해석 · 스냅샷 비교 (순수 함수, three 불필요) |
| `src/levels.js` | 레벨 8종 + 그림 데이터 + 채점 (순수 함수) |
| `src/drawView.js` | 판 · 복셀 큐브 |
| `src/stage.js` | 렌더러·조명·카메라 4시점 · 고정 스텝 루프 |
| `src/invariants.js` | 기하 불변식 (좌표·색 유한 · 일치율 범위) |
| `src/hud.js` | HTML 연결 + 목표 그림 캔버스 + 일치율 게이지 |
| `src/controls.js` | 포인터·키보드 입력 해석 |
| `src/main.js` | 상태 머신(놓기·지우기·채점) + UI 배선 |
| `common/parts/draw3d.test.js` · `src/levels.test.js` | 단위 테스트 15개 |

## 설계 메모

- **목표 그림은 문자 배열입니다.** 한 글자가 한 칸이고 `.` 은 빈 칸입니다.
- **일치율과 잘못 놓은 칸을 따로 셉니다.** 목표를 다 맞췄어도 다른 칸에 남은 게 있으면
  3성이 아닙니다.
- **카메라는 그림 크기에 맞춰 자동으로 물러납니다.**
- **`paint/`(11번째)와 다른 게임입니다.** 그쪽은 영역을 통째로 칠하고, 이쪽은 칸을 하나씩 놓습니다.

## 검증

```bash
node ../scripts/shot.mjs draw    # 4시점 캡처 + 자동 판정
npx vitest run draw common/parts # 단위 테스트 15개
```
