# 3D 빛 거울 공방

레이저 빛이 **거울**에서 반사되도록 거울의 방향을 바꾸는 퍼즐 게임입니다.
빛은 언제나 즉시 다시 그려지므로 "결과"를 기다릴 필요가 없습니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/laser/
```

## 조작

- **거울 누르기** — 방향이 `/` 와 `\` 로 바뀝니다
- **Space** — 채점 · **R** — 처음부터
- 마우스 드래그로 시점 바꾸기

## 규칙

- 빛은 거울에 닿으면 반사되어 90 도 꺾입니다
- 발사기에서 쏜 빛은 거울이 없으면 판 밖으로 나갑니다
- 미션은 빛이 **목표에 닿는 것**입니다
- 별점은 목표에 닿고 바꾼 거울이 par 개 이하이면 3성입니다
- 레벨마다 **최소 뒤집기 횟수(par)** 가 있습니다. 그 값은 *해답을 전수 조사해* 구합니다

## 구조

| 파일 | 역할 |
|---|---|
| `common/parts/optic3d.js` | 반사 벡터 · 격자 추적 · 전수 해법 탐색 (순수 함수, three 불필요) |
| `src/levels.js` | 레벨 8종 + par + 미션 판정 (순수 함수) |
| `src/laserView.js` | 판 · 거울 · 발사기 · 목표 · 빛줄기 |
| `src/stage.js` | 렌더러·조명·카메라 4시점 · 고정 스텝 루프 |
| `src/invariants.js` | 기하 불변식 (빛길이 유한 · 거울 존재 · 방향 올바름) |
| `src/hud.js` | HTML 연결 + 반사 횟수 |
| `src/controls.js` | 포인터·키보드 입력 해석 |
| `src/main.js` | 상태 머신(거울 전환·빛 추적·판정) + UI 배선 |
| `common/parts/optic3d.test.js` · `src/levels.test.js` | 단위 테스트 20개 |

## 설계 메모

- **반사는 벡터로 계산합니다.** `d' = d − 2(d·n)n`. `/` 거울과 `\` 거울은
  법선 방향만 다릅니다.
- **반사각이 입사각과 같은지 테스트로 고정합니다.** 부호가 빠지면 빛이 거울을
  통과해 버립니다.
- **빛은 격자 위에서 한 칸씩 쫓습니다.** 같은 칸을 다시 만나면 무한 순환이므로 중단합니다.
- **해답은 전수 조사로 찾습니다.** 거울이 5개면 32가지 조합을 모두 돌려
  목표에 닿는 조합과 최소 뒤집기 횟수를 구합니다.
- **처음 상태로는 절대 풀리지 않습니다.** 1층 테스트가 "거울을 하나도 안 써도
  닿으면 안 된다"를 확인합니다.
