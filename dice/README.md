# 3D 주사위 놀이

뱀과 사다리 보드에서 **주사위를 굴리고** 말을 움직이는 보드게임입니다.
도착한 칸에서 **더하기 문제**를 맞히면 한 칸 더 가고 1점을 얻습니다.
먼저 결승점에 도착한 사람이 이깁니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/dice/
```

## 조작

- **굴리기 (Space)** — 주사위를 굴립니다
- **정답 고르기** — 보기 3개 중 하나를 누릅니다 (1 · 2 · 3)
- **R** — 처음부터 · 마우스 드래그로 시점 바꾸기

## 규칙

- 주사위 값(1~6)만큼 말이 앞으로 갑니다
- **뱀과 사다리** 칸에 도착하면 한 번에 옮겨집니다. 옮겨간 뒤 다시 옮겨지지는 않습니다
- 결승점을 넘어가면 마지막 칸에서 멈춥니다
- 정답을 맞히면 1점을 얻고 한 칸 더 갑니다
- 두 사람이 번갈아 진행합니다

## 구조

| 파일 | 역할 |
|---|---|
| `common/parts/board3d.js` | 시드 난수 · 주사위 면 · 자세→면 매핑 · 보드 경로 · 이동 (순수 함수, three 불필요) |
| `common/parts/dice3d.js` | 주사위 메시(점 파이프) · 굴림 자세 계산 |
| `src/levels.js` | 보드 3종 + 턴 상태 머신 + 더하기 문제 (순수 함수) |
| `src/diceView.js` | 보드 칸 · 뱀과 사다리 표식 · 말 · 주사위 |
| `src/stage.js` | 렌더러·조명·탁자·카메라(보드 크기에 맞춰 자동 조절)·고정 스텝 루프 |
| `src/invariants.js` | 기하 불변식 (주사위 면 ↔ 보고 있는 값 · 말 위치 ↔ 칸 번호) |
| `src/hud.js` | HTML 연결 + 점수 + 문제 보기 |
| `src/controls.js` | 키보드 입력 해석 |
| `src/main.js` | 상태 머신(굴리기·이동·문제·턴) + 애니메이션 + UI 배선 |
| `common/parts/board3d.test.js` · `src/levels.test.js` | 단위 테스트 36개 |

## 설계 메모

- **굴림은 물리 시뮬레이션이 아닙니다.** 결과를 시드 난수로 정하고 **그 값이 위로 오는
  자세**로 주사위를 멈춥니다. 굴리는 동안의 회전은 연출입니다.
- **자세에서 면을 읽습니다.** 주사위가 실제로 어느 면을 향해 멈췄는지(3D 자세)를 숫자로
  읽어 "몇이 나왔는지"와 대조합니다. 화면에 6이라고 적혀 있는데 자세는 3을 향하면 오류입니다.
  이 검사는 2층 불변식이 매 0.5초마다 돌립니다.
- **같은 시드면 같은 게임입니다.** 주사위 값·점프·문제가 모두 같은 수열에서 나오기
  때문입니다. 굴림 연출만 별도 난수를 씁니다(규칙에 영향 없음).
- **점프는 한 번만 적용합니다.** 사다리를 타고 또 사다리를 타지 않습니다.
- **말의 위치는 칸 번호가 기준입니다.** 좌표는 칸 번호에서 뽑습니다. 말은 시각적으로
  겹치지 않게 살짝 벌려 두며, 불변식이 그 오차까지 고려해 비교합니다.
- **기대값을 숫자로 검사합니다.** 1200회 굴림의 평균이 3.5 ± 0.15 안에 들어오는지
  단위 테스트가 봅니다.
