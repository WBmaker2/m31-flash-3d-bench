# 3D 무리 유도

불빛(공짜 목표)을 움직여 새 떼를 링 게이트들을 차례로 통과시키는 유도 게임입니다.
새는 Reynolds 의 세 규칙(분리·정렬·응집)에 따라 서로 어긋나지 않게 날고, 무리를 이룹니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/flock/
```

## 조작

- **WASD · 방향키** — 불빛을 움직입니다. 새 떼가 불빛을 따라옵니다
- **드래그 · 휠** — 시점 회전과 확대 (카메라는 무리 중심을 따라갑니다)
- **R** — 현재 레벨을 다시 시작합니다
- **레벨 선택** — 레벨 창

## 규칙

- 다음 링이 초록색으로 켜집니다. 불빛을 그 링 가까이 데려가면 떼가 모이면서 통과로 인정됩니다
- **흩어짐**(무리 중심에서 평균 거리)이 커지면 별이 줄어듭니다. 불빛을 급하게 흔들지 마세요
- 제한 시간 안에 모든 링을 통과하면 클리어입니다
- 링 통과 판정은 "어떤 새가 선을 넘었다"가 아니라 **"불빛이 링에 있고 무리가 링에 모였다"** 로 봅니다.
  boids 무리는 목표 주위를 맴돌기 때문에 선을 넘는 순간은 안정적이지 않습니다

## 설계 메모

- **규칙별로 성질을 테스트합니다.** "분리 규칙은 가까운 두 새를 멀어지게 한다",
  "정렬 규칙은 이웃의 평균 방향을 가리킨다" 처럼 각 규칙을 따로 꺼내 검증합니다.
  에머전트 행동은 "그냥 잘 보이면" 통과시킬 수 없기 때문입니다.
- **dt 독립성을 확인합니다.** dt/2 로 두 번 돌린 결과와 dt 로 한 번 돌린 결과가
  가까운지 확인해 적분이 스텝 크기에 의존하지 않는지 봅니다.
- **흩어짐의 평형값은 재면으로 정했습니다.** 응집 반경이나 가중치를 바꿔도 무리의
  평형 흩어짐은 13~14 m 로 거의 일정했습니다. 판정 기준은 그 실측값에 맞췄습니다.
- **링은 무리 크기에 비례해 잡습니다.** 반경 9 m 는 "무리 일부가 통과"가 되면서도
  링이 무리 전체를 삼키지 않는 크기입니다.
- **시작 영역을 첫 링 뒤로 제한합니다.** 산포된 새가 처음부터 링을 통과한 것으로
  세어지면 아무것도 안 해도 통과가 됩니다.
- **개체 400 마리도 InstancedMesh 두 개로 그립니다.** 몸통과 날개가 각각 하나라
  드로 콜이 늘지 않습니다.
