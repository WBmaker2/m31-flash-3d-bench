# 3D 균형저울

시소매 저울에 **추를 올려** 수평으로 맞추고, 무게까지 목표에 맞추는 게임입니다.
어느 쪽에 얼마나 올렸는지가 결과를 바꾸기 때문에 **무게중심**을 느끼게 됩니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/balance/
```

## 조작

- **추 고르기** — 팔레트에서 무게(1 · 2 · 3 · 5kg)를 고릅니다
- **저울판 위를 클릭** — 그 홈에 추를 올립니다 · 다시 누르면 뺍니다
- **1~4** — 무게 고르기 · **Space** — 채점 · **R** — 모두 빼기
- 마우스 드래그로 시점을 바꿉니다

## 규칙

- 추를 올릴 때마다 저울이 기울고 **무게중심 표시( cones )** 가 움직입니다
- 미션은 두 조건입니다. **수평(모멘트 합 0)** 이면서 **총 무게가 목표**
- 같은 무게라도 받침대에서 먼 쪽에 놓으면 더 세게 당깁니다
- 별점은 두 조건 달성 + 최소 개수 이하로 올리면 3성입니다
- 레벨마다 **최소 개수**가 있습니다. 그 값은 *목표를 달성하는 최소 추 개수*라
  항상 달성 가능합니다

## 구조

| 파일 | 역할 |

| `src/levels.js` | 레벨 8종 + 기준 해법 + par + 미션 판정 (순수 함수) |
| `src/balanceView.js` | 저울판 · 받침대 · 추 · 무게중심 표시 |
| `src/stage.js` | 렌더러·조명·카메라 4시점 · 고정 스텝 루프 |
| `src/invariants.js` | 기하 불변식 (회전각 == 계산값 · 추 위치 유한) |

## 설계 메모

- **수평 = 무게중심이 받침대 위**입니다. 모멘트 합이 0 인 것과 같은 말이고,
  두 표현을 다 검사합니다.
- **기울기는 `atan2(Στ, Σm·g)`** 입니다. 저울판의 회전각이 이 값과 1e-9 안에서
  맞는지를 2층 불변식이 매 0.5초마다 검사합니다.
- **파생 상태는 항상 다시 계산합니다.** 추를 올릴 때마다 무게중심과 기울기를
  처음부터 계산합니다(변화량만 갱신하면 기울어짐이 누적됩니다).
- **최소 개수(par)는 전수 조사로 확인합니다.** 목표 무게를 넘는 조합은 자르고
  모든 조합을 돌려 최소 개수를 구합니다.
- **받침대 위에는 올릴 수 없습니다.** 그 홈은 계산에서 제외합니다.
