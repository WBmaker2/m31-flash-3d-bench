# 3D 기어 공방

나무 판에 **톱니바퀴를 끼워** 크랭크와 연결하는 게임입니다.
끼운 톱니바퀴는 크랭크와 맞물려 **비율만큼 빠르게, 반대 방향으로** 돌아갑니다.
미션(예: "미션 톱니바퀴가 초당 1.5바퀴")을 맞추면 별을 받습니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/gears/
```

## 조작

- **빈 칸 클릭** — 고른 크기의 톱니바퀴를 끼웁니다
- **끼운 톱니바퀴 클릭** — 뺍니다
- **1~5** — 크기 고르기 (8 · 12 · 16 · 20 · 24톱니)
- **Space** — 채점 · **R** — 모두 빼기
- 마우스 드래그로 시점을 바꿉니다

## 규칙

- 판에 박힌 **칸**은 정해져 있습니다. 크기가 다르면 그 칸에 들어가지 않습니다
- 톱니바퀴끼리 **겹치면** 끼울 수 없습니다. 서로 닿는 거리일 때만 맞물립니다
- 맞물린 톱니바퀴는 방향이 **반대**로 돕니다. 두 번 이어지면 처음과 같은 방향입니다
- 톱니바퀴 세 개가 고리를 만들면 서로 잠겨 돌아가지 않습니다
- **속도**는 최종 톱니바퀴의 톱니 수로 정해집니다 (크랭크 톱니 수 ÷ 마지막 톱니 수)
- 별점은 미션 달성 + 톱니바퀴를 par 개 이하로 쓰면 3성입니다
- 레벨마다 **par** 가 있습니다. 그 값은 *미션을 달성하는 최소 톱니바퀴 수*라 항상 달성 가능합니다

## 설계 메모

- **회전이 회전을 만듭니다.** 앞의 9개 게임엔 "각속도가 링크를 따라 전파된다"는 관계가 없었습니다.
  이 게임의 핵심은 `ω_B = −ω_A × (N_A / N_B)` 하나입니다.
- **부호가 빠지면 조작이 거꾸로 됩니다.** 맞물린 톱니바퀴는 방향이 반대라는 사실을
  비율에 곱해 전파합니다. 한 단·두 단·세 단을 모두 수치 테스트로 고정했습니다.
- **톱니 위상도 지켜야 합니다.** `θ₁·N₁ + θ₂·N₂` 는 맞물린 동안 일정해야 합니다.
  이게 깨지면 톱니가 서로 파먹습니다. 화면으로는 안 보이기 때문에 1층 테스트와
  2층 불변식이 함께 검사합니다.
- **위상 오프셋을 간선마다 계산합니다.** 톱니가 실제로 맞물려 보이려면 톱니 중심이
  두 톱니바퀴의 중심을 잇는 선 위에 있어야 합니다. 각도만 맞추면 톱니끼리 부딪혀 보입니다.
- **홀수 고리는 모순입니다.** 톱니바퀴 세 개가 고리를 만들면 비율이 모순됩니다.
  게임은 그 조합을 "잠겼어요"로 표시합니다.
- **레벨의 par 는 열거로 확인합니다.** 모든 배치를 전부 돌려 최소 톱니바퀴 수를
  계산하고 par 와 같은지 검사합니다 (`maze/` 의 par = BFS 최적 경로와 같은 원칙).
- **판 크기는 레벨마다 달라집니다.** 카메라도 판 크기에 맞춰 자동으로 물러납니다.
