# 3D 전개도 맞추기

색칠된 정육면체를 보고 **어느 전개도가 이 상자가 될지** 고르는 공간지각 퍼즐입니다.
전개도를 접는 것을 머릿속으로 해 봐야 하는 문제입니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/net/
```

## 조작

- **전개도 보기 누르기** — 고르기 · **1~4** — 보기 고르기
- 마우스 드래그로 시점 바꾸기

## 규칙

- 목표 상자의 6면 색이 정해져 있어요
- 보기 4개는 같은 모양의 전개도인데 색 배치가 다릅니다
- 그중 **하나만** 접었을 때 목표 상자와 똑같아집니다
- 틀려도 다른 보기를 고를 수 있어요

## 구조

| 파일 | 역할 |
|---|---|
| `common/parts/net3d.js` | 굴리기 · 접기 · 유효 판정 · 면 색 비교 (순수 함수, three 불필요) |
| `src/levels.js` | 레벨 8종 + 보기 4개 생성 + 정답 판정 (순수 함수) |
| `src/netView.js` | 목표 상자 · 전개도 보기 |
| `src/stage.js` | 렌더러·조명·카메라 4시점 · 고정 스텝 루프 |
| `src/invariants.js` | 기하 불변식 (보기 개수 · 색 유한 · 범위) |
| `src/hud.js` | HTML 연결 |
| `src/controls.js` | 포인터·키보드 입력 해석 |
| `src/main.js` | 상태 머신(고르기·판정) + UI 배선 |
| `common/parts/net3d.test.js` · `src/levels.test.js` | 단위 테스트 16개 |

## 설계 메모

- **전개도는 굴리는 큐브로 접습니다.** 큐브를 한 칸씩 굴리며 바닥면을 기록하면
  그 칸이 접혔을 때의 면이 됩니다. 회전 규칙 하나만 정확하면 됩니다.
- **6면이 겹치면 정육면체가 아닙니다.** 1층 테스트가 전개도 6종을 전부 검사합니다.
- **정답은 하나뿐입니다.** 보기 4개 중 목표와 같은 것이 정확히 하나인지 검사합니다.
- **면 색이 왕복합니다.** 목표 색 → 칸 색 → 접힌 면 색으로 돌아오면 같은 색이어야 합니다.

## 검증

```bash
node ../scripts/shot.mjs net    # 4시점 캡처 + 자동 판정
npx vitest run net common/parts # 단위 테스트 16개
```
