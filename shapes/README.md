# 3D 도형 조립실

반투명한 목표 모양을 블록으로 채우는 3D 공간 지각력 게임입니다.
블록은 3×3×3 격자(복셀)에 놓이고, 다 채우면 목표와 정확히 일치하는지 판정합니다.

## 실행

```bash
python3 -m http.server 5174
# http://localhost:5174/shapes/
```

## 조작

- **트레이의 블록 클릭** — 집어 들고 격자 위를 따라다닙니다
- **보드 클릭** — 놓습니다. 목표 밖이거나 이미 채운 칸이면 거절됩니다
- **R / Q** — 블록 회전 (서로 다른 모양만 순환)
- **Z** — 마지막 블록 되돌리기
- **레벨 선택** — 레벨 창 (별점과 잠금 상태 표시)

## 구조

| 파일 | 역할 |
|---|---|
| `src/rotations.js` | 24회전군 생성 + 칸 정규화 + 방향 중복 제거 |
| `src/blocks.js` | 블록 8종 정의 (단위 큐브 칸 집합) |
| `src/levels.js` | 레벨 8종 (목표 칸 · 제공 블록 · 최소 블록 수) |
| `src/assembly.js` | 배치·겹침·완료 판정 + 점수 계산 (순수 함수) |
| `src/invariants.js` | 기하 불변식 (목표 밖 배치 · 블록 겹침 · 격자 밖 칸) |
| `src/shapes.test.js` | 단위 테스트 25개 (회전군 · 배치 판정 · 레벨 데이터) |
| `src/main.js` | 3D 씬, 트레이, 미리보기, 레벨 진행, 결과 화면 |
| `src/stage.js` | 렌더러·조명·사선 격자 바닥·고정 스텝 루프·피킹 |

## 설계 메모

- **회전 24개를 손으로 적지 않고 생성합니다.** 부호 순열 행렬에서 행렬식이 +1인 것만
  뽑으면 24개가 나옵니다. 이걸 순수 함수로 만들어 유닛 테스트로 고정했기에
  "방향 인덱싱" 실수가 원천적으로 막혔습니다.
- **블록은 전부 정육면체 칸 집합입니다.** 삼각기둥 같은 비직교 블록을 넣지 않아
  회전과 판정이 순수 집합 연산으로 남습니다. 정육면체 계열만으로도 공간지각력을
  충분히 다룰 수 있습니다.
- **방향은 정규화 후 비교합니다.** 원점 기준으로 보면 +x와 -x가 다른 방향으로 세어져
  막대 3칸의 방향이 6개가 됩니다. 최소 모서리를 원점으로 옮긴 뒤 비교해야
  실제로 다른 모양만 순환합니다.
- **배치 판정은 해석적입니다.** `배치한 칸 ⊆ 목표` 이고 `겹침이 없으면` 진행,
  `합집합 == 목표` 이면 완성. 물리엔진이나 충돌 판정이 필요 없습니다.
- **레벨 1과 2는 목표가 같습니다.** 4칸을 정육면체 4개로 채우느냐, 판자 하나로
  채우느냐만 다릅니다. 같은 목표를 다른 도구로 푸는 차이가 par(최소 블록 수) 점수로
  드러납니다.
